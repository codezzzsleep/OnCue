# OnCue 界面契约（tests/ui）

这份契约规定 OnCue 每个界面状态该显示什么、每个操作改变什么、每个宿主服务的每种回复怎么处理。`tests/ui/` 里的场景按这里的行号命名，用 [splash-app-verify](https://github.com/OctoSense-org/OctoSense-App-Flow/tree/main/skills/splash-app-verify) 在 card-host 里运行。宿主回复由场景注入，形状与错误原文取自 Rinx `fdcfed1` 源码，出处见第三节。

## 一、界面与状态

| 编号 | 状态 | 必须显示 | 不得显示 |
| --- | --- | --- | --- |
| S1 | 首次打开（样例） | 「OnCue · 群聊试映室」；「载入群聊」「我想说」输入框「试映下一幕」都在首屏内 | 「发到群里」（样例不能发送） |
| S2 | 样例试映后 | 「样例的三种说法已显示。」；三条路线各一个「选用这句」 | 任何宿主调用 |
| S3 | 群聊已载入 | 「原消息已载入，共 N 条。」；房间名；展开后每条带 ☑ #编号 | 样例消息 |
| S4 | 未允许助手 | 「允许当前范围内的试映与修订」；点试映只提示，不调用助手 | |
| S5 | 已允许 | 「已允许 · 点这里撤回」 | |
| S6 | 三种说法已生成 | 「三种说法好了。」；每条路线的建议和它依据的原文 | |
| S7 | 群里有新消息（候选已过期） | 「已过期：群里新增 N 条消息…」和新消息原文；「选用这句」「应用修订」变灰且点了不读群 | |
| S8 | 发送确认区 | 「将发到：房间名」、完整正文、「确认发送」「返回修改」 | |
| S9 | 已发出（回读看到） | 「已发到 房间名。刚才读回时看到了这条。」；按钮变「已发送」 | 「发送失败」 |
| S10 | 发出结果未确认 | 「…尚不能确认…」或「…可能已发送…」；「重新读取确认」 | 「发送失败」；自动重发 |
| S11 | 宿主报错（任意服务） | 第三节对应的中文句子 | 宿主英文原文；与出错服务不符的前缀（如助手出错却说「没有读到群聊」） |
| S12 | 存储损坏 | 「存储无法读取、格式损坏或版本未知；保留原文件，暂停写入。」 | 覆盖原文件 |

| --- | --- | --- | --- |

| A2 | 允许 / 撤回（`cue_privacy` 里的按钮） | 允许只对当前房间和当前勾选有效 | 否 |

| A13 | 重新打开后载入同一房间 | 恢复该房间主稿 | 读 |

## 三、宿主服务（Rinx fdcfed1）

所有服务每次请求只回调一次（App Flow SCRIPT-API「Host services」；Rinx `src/miniapps/ui.rs` 只把完成事件交给脚本）。

| 服务 | 成功回复 | 必须处理的失败（宿主原文 → 界面） |
| --- | --- | --- |
| `matrix.room_info` | `{room_id, room_name}` | 授权过期、账号切换、未登录、未授权、未绑定房间、无服务（见下表） |
| `matrix.read_messages` | `{messages: [{sender, sender_id, event_id, body ≤500 字, ts, msgtype, room_id, unread}], has_more}`（`room.rs` 38–51、233） | 同上；格式异常 |
| `matrix.account_info` | `{user_id, display_name, has_avatar, ignored}`（`account.rs` 30–35） | 同上；账号与上次不同 → 「账号已经切换。请用当前账号重新打开 OnCue。」 |
| `matrix.send_message` | `{}`，不带 event_id（`send.rs` 15–27） | `couldn't send the message: …`（含限流 429）→ 结果未确认，不自动重发 |
| `octos.session.open` | `{open: true, model: {lane}}` | 助手未开启、OctoSense 未给助手权限、授权过期（`host/service.rs` 71–100） |
| `octos.turn.start` | `{turn_id, text}` | 模型限流 / 出错；不回复（应用自己的 90 秒期限）；回复不合格 |
| `octos.turn.interrupt` | `{}` | 忽略 |

| 宿主错误包含（不分大小写） | 界面显示 |
| --- | --- |
| `authorization expired` | 授权已过期。Rinx 打开小程序一小时后，或关闭应用以后，会收回授权。请关闭 OnCue，再从小程序列表重新打开。草稿已经保存的不受影响。 |
| `account changed` | 账号已经切换。请用当前账号重新打开 OnCue。 |
| `not logged in` | Rinx 没有登录。请先登录，再打开 OnCue。 |
| `not attached to a room` | 这次打开没有选房间。请关闭应用，导入时填上房间再打开。 |
| `not granted` | 宿主没有授权这项房间或账号服务，请重新打开并检查授权。 |
| 群聊服务（`matrix.*`）的 `no service answers` | 当前宿主不提供群聊服务，请在 Rinx 里打开。 |
| `429` / `rate limit` / `too many requests` / `M_LIMIT_EXCEEDED` | 请求太频繁，被限流了。请等一分钟再试；草稿没有改动。 |
| 助手服务（`octos.*`）的 `assistant is off`、`has not given Rinx assistant access`、`no local assistant runtime`、`access token again`、`no service answers` | 这个宿主现在没有可用的助手。可以先手写草稿；在 Rinx 设置里打开助手后再试。 |
| 其他 | 按出错的服务给前缀，后接原文：读群聊「没有读到群聊：」，助手「助手暂时不可用：」，发送「宿主原话：」（接在「请求报错，可能已发送；…」之后） |

前三种错误（授权过期、账号切换、未登录）同时撤销对助手的允许，界面上的允许按钮要同步变回「允许当前范围内的试映与修订」。
