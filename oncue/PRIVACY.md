# OnCue 数据说明

OnCue 在 Rinx 中读取已授权房间的最近文本，协助你比较说法、修订并保存私人草稿。应用不申请或调用 Matrix 发送服务。

## 来源与授权

- Rinx 授权的房间名称、稳定房间 ID 和最近最多12条文本消息。显示的是宿主返回的原文片段，宿主可能截短长消息。
- 你输入的台词、表达目标、补充条件、草稿和修订要求。
- Matrix 登录及模型凭据由宿主管理，应用不接触。

房间读取许可与模型请求许可分开。在数据范围卡中允许后，每次点击试映或修订会发送当时的输入；许可仅在当前打开实例的房间和勾选消息范围内有效。改变范围、重新载入、撤回或关闭应用后须重新允许。

## 送给模型的内容

试映请求包含所勾选消息的原始编号与正文、当前台词和目标；修订请求另包含当前草稿和修改要求。重试包含同一请求及检查失败原因。发送者标签不放入请求，但正文仍可能含姓名或其他可识别信息，这不是完整匿名化。

应用不直连外部网络，Rinx 的 Matrix 服务和宿主模型可能联网。宿主可保留先前会话并决定工具权限；应用调用打开会话不保证清空历史。取消勾选、停止请求或删除本地记录不会删除宿主或模型服务已有内容。使用前请确认你有权把所选消息用于该模型。

## 检查边界

生成协议检查七节、每路线引用范围、数字/单位的字面匹配和部分完成/承诺措辞。修订协议检查三节并把候选暂存，只有明确应用才改变编辑框。原文由程序按编号取出；引用存在不证明支持建议的含义。否定、条件、单位语境等仍可能判断不完整，用户手工编辑也不继承助手候选的检查状态。

## 本地保存与删除

- 草稿按宿主账号和房间 ID 隔离，样例使用独立记录。每个房间有主稿、A、B三个槽。
- 每槽保存文本、对照原稿、来源编号/快照标识、目标、台词、生成时间及文本版本，不保存整批聊天正文或全部假设对白。
- 最多10个房间记录（含样例），每份文本最多8000 UTF-8字节，记录文件最多512 KiB。到限停止写入，要求手动清理。
- 保存检查写入及逐字回读。仅支持一个活动写入窗口；存储没有跨进程锁或崩溃原子性保证。文件损坏、未知格式或写入结果不确定时暂停写入，保留编辑框，需重新读取或明确清空恢复。
- 旧版主稿/A/B不自动显示或归属当前房间；你可手动复制并保存。新记录和旧版副本分别删除。
- 删除本房间草稿移除其新格式记录并回读确认，清除当前编辑和候选；删除旧版文件另需确认。无法读取的新格式文件只能明确清空全部房间记录。应用不保留自动恢复备份。

删除属于应用可见的逻辑移除，不承诺磁盘取证级擦除。宿主账号目录、日志、模型历史的保留和删除由宿主及服务商管理。
