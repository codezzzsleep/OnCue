# OnCue 数据说明

OnCue 用选定聊天片段和一条尚未发出的台词做私人排练。原消息保持可回看，模型生成的接话标为假设；应用不预测群友会如何回复，也没有自动发送群消息的能力。

## 服务器体验版

本地规则模式不调用模型。模型模式在使用者确认取材后，把当前片段和台词送到服务器配置的 MiniMax 接口；这次请求会产生模型用量。服务器只在处理请求期间使用这些内容，没有会话内容数据库。

点击保存才会把草稿或排练存档写入当前浏览器的本地存储，最多保留 12 个存档。删除存档和清空草稿会移除相应浏览器记录；已经导出的文本文件仍由使用者自行管理。不同浏览器之间没有自动同步。

模型 API Key 由服务器从仓库外的私有文件或环境变量读取，不发送到网页，也不加入模型提示词。网页访问口令与模型 Key 是不同的配置。

## Rinx 原生小程序

Matrix 登录凭据由 Rinx 宿主管理。小程序申请读取本次附加并授权房间的最近 12 条消息，消息服务会限制单条正文长度。原生模型试映使用 OctoSense 共享的 Octos 服务，因此选定片段会进入该服务所配置模型的请求上下文。

原生草稿保存到 Rinx 为当前账号和应用分配的本地存储。保存草稿不会发到群聊。关闭应用会结束本次宿主服务授权；已经保存的草稿与宿主会话数据的保留方式仍由 Rinx/Octos 的实际配置决定。

原生运行的实测范围以仓库验证记录为准；服务器体验版的通过结果不代表原生流程已经通过。
