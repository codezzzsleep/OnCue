# v0.2 验证记录

日期：2026-09-30。

## 服务器体验版 v0.2 已检查

- Python 3.12 环境启动普通 HTTP 服务，不需要图形桌面。
- 15项 Python 检查通过：输入边界、三组样例、模型协议、逐字来源摘录、
  已知出游条件提示、未核实费用数字、访问口令、来源与主机限制、注销、模型失败反馈。
- Node 静态语法检查通过。
- 17项初次 DOM 联调检查通过，使用 JSDOM 与实际 Python HTTP 服务，
  包括真实 MiniMax 模型回合经过前端处理、草稿保存与导出、存档恢复、版本对照、
  自定义消息作为文本显示、输入改变与过期响应、模型取材确认。
- 已使用用户授权提供的 Key 调用 MiniMax-M2.7：直接适配器调用、实际 HTTP 路由调用、
  前端事件处理到 HTTP 路由的真实调用均成功。前两次响应各报告1102、1496 total_tokens。
- 两次保存的真实样例均返回三条路线，各有6处可与原消息逐字核对的来源摘录。
- 据实测输出补充“待确认”提示。来源摘录存在不能证明整段建议或假设都有事实依据。
- 加入待确认提示与清空草稿后，19项 DOM 检查通过；此次使用之前的真实模型结果作为固定样例，未重复消耗模型额度。
- 真实样例输出见 docs/sample-live-result.json，取材为虚构出游群，不含凭证。
- 可核对的汇总记录见 docs/verification.json。
- Key 只存于交付目录之外的临时运行配置，不进入前端、源码、报告或打包文件。
