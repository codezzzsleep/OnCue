## 一、已实测通过

### 1. 分页与阅读（412×892 与 990×613 双视口）

8 个夹具在两种视口下页数**逐条相同**，且末页不越界（末页再翻与末页同图）：

| 夹具 | 页数 |
| --- | --- |
| 01 长单行中文 | 34 |
| 02 连续 ASCII | 21 |
| 03 连续空格 | 27 |
| 04 多行 A/B | 46 |
| 05 长对白 | 51 |
| 06 emoji + 组合 | 32 |
| 07 空格边界 | 28 |
| 08 极短行 | 46 |

真实房间**最新 12 条**在两种视口下页数相同：3, 4, 3, 5, 5, 5, 5, 5, 5, 5, 5, 5。
助手回复的**七块**文本在两种视口下页数相同：5, 21, 4, 20, 6, 25, 8。
右侧工作区（对白/建议）在两种视口下均**未被页脚裁切**。

### 2. 逐页拼接无损

应用自身调用分页函数并把各页拼回原文，逐字符与逐字节比较：**全部夹具相等**
（例如 01：263 字符 / 783 字节，拼回后完全相同）。

### 3. 逐句播放

| 子项 | 结果 |
| --- | --- |
| 「下一句」每点一次 +1 且保持暂停 | ✅ |
| 「播放」跨两个间隔各 +1 | ✅ |
| 暂停后等待 3.4 秒计数不前进 | ✅ |

### 4. 全部控件可达

产品共 28 个按钮，在真实渲染中逐个点击：**28/28 有响应、进程不崩溃**。

### 5. 字素边界（不让 emoji 被拆到两页）

覆盖 15 类边界（组合标记、肤色、VS16、keycap、ZWJ 家族、旗帜、天城文 virama、
阿拉伯 harakat、希伯来点、泰文、谚文 Jamo、Combining Half Marks、半角浊音、
emoji tag、Prepend）× 每类 16 个折页偏移，在两种视口下：

- **0 处页边界落在字素簇内部**（修复前同夹具基线为 **39 处**）；
- 页数不变，拼接仍逐字符/逐字节相等。

### 6. 在 Rinx 宿主内装载与运行

走 Rinx 官方 Developer 路径 `Discover → Mini apps → Import an app`：

- Review 面板显示 `0.4.4 · Local unsigned bundle`，**Allowed room 与所选测试房间精确一致**；
- Run 后应用真实运行；导入快照 `miniapps/imports/rinx-miniapp-*` 的资源摘要**与本包摘要精确相等**；
- 应用内样例路径交互正常。
