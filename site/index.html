01 / FOUR ACTS, ONE CONVERSATION

一句话的四幕。

从群里的原话出发，
再回到真实的对话里。

ACT 01 / READ

先听清，
再开口。

打开就读所选群聊的最近消息。保留原编号，由你勾选这次参考哪些话，再写下想说的内容和表达目标。

  • 最近 12 条消息，原话呈现
  • 澄清条件 / 礼貌拒绝 / 推动下一步
  • 只参考你选择的消息
ACT 02 / REHEARSE

换一种说法，
保留你的意思。

助手参考原话提出三种表达，每种附上依据。程序逐条核对引用、数字和承诺句式；哪一条没通过，就拦哪一条并说明原因。

  • 三种说法，逐条核对
  • 通过核对的推荐句进入草稿
  • 可以自己改，也可以再请助手修订
ACT 03 / SEND

最后那一下，
始终由你决定。

先展开确认区，核对发到哪个群、完整正文，再确认发送。发送前复核新消息，发送后读回核实；结果不明时只重新读取。

  • 两步确认，正文原样发送
  • 群里有新消息，先标出来
  • 发送结果不确定，不自动重发
ACT 04 / REFLECT

发出去之后，
对话还在继续。

点「看反响」，把群友之后的回复按原话列出来。助手对照试映时的预想，给出下一句建议，通过核对后再交给你。

  • 真实回复与助手对照分开展示
  • 下一句也要通过规则检查
  • 没有新回复，就如实说明

03 / A CLEAR DIVISION OF LABOR

让助手帮忙，也把边界写清。

措辞可以有多种，
权限和依据必须明确。

01 / AGENT

助手给选择。

理解你想澄清、拒绝或推进的目标，提出三种措辞，按你的要求修订。助手的预想对白与群友原话分别呈现。

02 / PROGRAM

程序做核对。

检查结构、引用、数字与承诺句式，处理请求期限和迟到回复。草稿按群保存在本机，支持 A / B 两版对照。

03 / YOU

你来做决定。

选择参考消息，判断建议是否符合本意，修改草稿，核对房间与全文。应用只在你明确确认后发送。

⌁

OnCue 本身不直接联网、不持有密钥。群聊和助手服务由 Rinx 授权，关闭应用或授权到期后由宿主收回。

使用边界与未验证

引用、数字和承诺句式检查是有限的规则约束；语义是否符合原文与本人意图，仍需要你判断。手工编辑的草稿需要重新核对。草稿仅支持一个写入窗口，没有跨进程锁和崩溃原子性保证。

Rinx 与宿主助手可能联网并保留历史；删除 OnCue 本地草稿不影响宿主或 Matrix 端的数据。

未验证：应用在 macOS、Windows 与移动端的运行、商店安装路径，以及语义正确性、数值归属和规则误拒率。完整范围见验证记录与产品说明。
