## 脚本（时间轴）

### 0:00–0:20 ｜ 一句话定位 + 合规声明
**画面**：Rinx 的 Mini apps 面板，显示 `OnCue · 群聊试映室`
**说**：
> "OnCue 是一个**发消息前的私人排练室**。它读你**授权房间**的真消息，请设备上的助手预演三条
> 不同方向的下一幕，你逐句看完、改好存草稿，**由你自己决定发不发 —— 应用本身不发任何消息**。"

### 0:20–0:45 ｜ 必要授权 + 启动
**操作**：`Import an app` → 填包路径与房间 → `Review bundle`
**画面**：面板显示
```
OnCue · 群聊试映室 0.4.4 · Local unsigned bundle
Services: storage, matrix.room_info, matrix.read_messages, octos.session.open, octos.turn.start, octos.turn.interrupt
Allowed room: !2TfOHq2ZGCYO5WJmDC:matrix.rinx.chat
```
**说**：
> "宿主逐项列出它要的服务和**唯一允许的房间**；我点 Run 才为**本次会话**授权。"

### 0:45–1:10 ｜ 真实输入 → 真实数据
**操作**：`Run` → 点「载入群聊」
**画面**：标题变为 **「OnCue 试映室测试房」**；状态行 **「原消息已载入，可逐条翻看…」**
**说**：
> "房间名和 12 条消息都来自赛事服务器上的真实房间 —— 不是样例数据。"

### 1:10–1:50 ｜ Agent 执行
**操作**：点「试映下一幕」
**画面**：状态行 **「Agent 正在排练三个可能的下一幕…」** → **「现场摘要已就绪…」**
**说**：
> "这一句请求被交给设备上的助手内核（octos）。三条路线是：**顺着这句 / 换个问法 / 换个玩法**。"
**可出示的旁证**（可选，10 秒）：内核日志
`turn: calling LLM … session=_main:api:octosense#peerctx-rinx-…oncue-s…` →
`LLM response received stop_reason=EndTurn response_content_len=1839`

### 1:50–2:20 ｜ 结果核验（逐句播放）
**操作**：点「播放」/「暂停」/「下一句」/「重播」；点「摘要」逐页读
**画面**：对白按页推进；状态行「正在逐句播放「顺着这句」的假设对白。」
**说**：
> "假设对白**逐句**播放，可以暂停、单步、重播。这里明确标注：**原消息是事实线索，
> 假设对白仍需我自己判断**。"

### 2:20–2:40 ｜ 草稿 A/B + 边界
**操作**：改一句 → 「存 A」 → 再改 → 「存 B」 → 「取 A」「显示 B」
**画面**：状态行「版本 A 已保存并回读确认；关闭后可以取回。」
**说**：
> "两版草稿存在应用自己的隔离空间里，**关闭再打开仍在**。全程**没有任何消息被发出**。"

### 2:40–2:55 ｜ 失败状态（必展示）
**操作**：清空房间授权的实例里点「载入群聊」
**画面**：状态行 **「没有读到群聊：this mini-app is not attached to a room」**
**说**：
> "没有房间授权的实例，房间绑定的调用会被宿主**明确拒绝** —— 应用如实显示，不崩、不伪造。"

### 2:55–3:00 ｜ 接收者独立授权
**操作**：切到账号 B 的实例，`Review` 面板
**画面**：**`Allowed room: None`**；B 必须自己授权
**说**：
> "换一个账号打开同一个应用，**必须自己授权**，`Allowed room` 是空的 —— **不继承发送者的权限**；
> 它的草稿目录也是自己的，看不到我的草稿。"
