## 这份录屏没有覆盖的（如实说明）

1. **没有旁白和字幕**——我没有语音合成能力。上表“说什么”一列就是现成的解说词，按时间点对齐即可配音。
2. **接收者独立授权不在本视频内**：需切到第二个 Rinx 实例，与主流程无法放在一次连续录屏里。该部分证据见 [RECIPIENT-CONSENT-DEMO.md](<RECIPIENT-CONSENT-DEMO.md>) 与 `oncue/VERIFICATION.md`（`Allowed room: None`、房间绑定拒绝）。窄窗 412×892 的同版验收也在 `VERIFICATION.md`。
3. **失败态不在本视频内**：本次回合一次成功。协议被拒时的自动重试与提示，证据在 `oncue/tests/` 的受控断言与 `evidence/checkpoint-0.4.6/native-final/`。
4. **视频没有展示**：读房授权三选项 sheet、deny 分支、实例租约撤销、迟回复——这些按 `VERIFICATION.md` 第四节列为未验证。

## 复现方式

```sh
# 1) 生成未签名开发副本（不触碰仓库里的签名包）
DEV="$(mktemp -d /tmp/oncue-dev.XXXXXX)"
python3 oncue/tools/prepare_dev_bundle.py "$DEV/bundle" --hub "$OCTO_HUB"

# 2) 在已登录的 Rinx 里 Discover → Mini apps → Import an app
#    填 $DEV/bundle 路径与你自己的授权房间 → Review → Run

# 3) 应用内：载入群聊 → 试映下一幕 → 摘要/三路线 → 播放 → 存 A/B → 取回
```

驱动与录制工具在 `oncue/tools/`（`native_bridge.py`、`rinx_session.py`、`native_acceptance.py`），
它们是测试输入客户端，不是网页入口；作品中不存在网页路径。
