
## 六、Run 后的交互实测（当前 0.4.4，homeserver=matrix.org）

| 操作 | 结果 | 证据 |
| --- | --- | --- |
| 点 `试映下一幕` | **界面响应**：状态变为 `样例预设已展开；这些对白不是对真实群友的预测。` → 样例路径在当前包内正常 | `rinx-rehearse-demo.png` |
| 点 `载入群聊` | **界面无可见状态变化**（状态仍为样例路径文案）；宿主日志在这段时间**没有** room/read 相关行 | `rinx-room-03-status.png` |

**内嵌视图尺寸限制（实测）**：应用在 Rinx 内的可视区在 `现场原消息` 处被裁切
（`现场原消息` 标签在 y≈630，其后仅约 30px），**消息列表与分页控件都看不到**。
因此"room 最新 12/13 条"的**逐条可视证据无法在这个内嵌尺寸下取得**，
需要更高的宿主窗口或换用能取到消息区的宿主尺寸。

**不引用 0.4.3 时期的任何 Rinx 侧结论**。homeserver = `matrix.org`（非赛事 `matrix.rinx.chat`）。
