5. 再观察约 10s（含中间 dump）期间，路线 B 计数器**一直停在 `0 / 2`**，status 一直为「已选…」而非「正在播放…」

### 4.2 变体实验（换 C 路线复测）

### 4.3 收尾：重播
- 先点 `A 顺着说`（(619, 377)），再点「重播」（(840, 421)）→ +3s：

### A4 判定

- 【INFO／局限】重选某条路线会把该路线复位到 `0 / n`，因此「泄漏的旧 timer 绑定在旧路线对象上」这一形态无法通过界面直接观测；本次只能确认**界面可见计数不继续增长**。
