## 2. 逐页核对（每个 fixture、每个视口都要做）

对每一页执行：

1. 读"第 X 页 / 共 Y 页"（右栏阅读区）或"第 X 页 / 共 Y 页"（左栏原消息），
   记录下来：`Y` 应与离线自查 `fixtures/simulate_paginate.py` 输出的页数一致
   （预算不同：原消息 4 行/页，阅读区 5 行/页）。
2. 肉眼核对本页文本：应只有本页内容，不出现上一页/下一页的片段。
3. 数本页视觉行数：应 ≤ 预算（原消息 ≤4、阅读区 ≤5）；
   源文本以 `\n` 结尾时末页允许多一条空行。
4. 记录翻页耗时/卡顿（单选，作为非功能参考）。

### 拼接完整性（关键）

把一个 fixture 的**所有页**按顺序抄出来（或截图后 OCR），与 fixture 原文做字符级对比：

- 不缺失、不重复、不重排；
- 空格、换行、Tab 原样保留；
- F6 的 emoji / 组合字符逐个对上；
- F7 跨页处字符连续（前页末字符 + 后页首字符 == 原文对应位置）。

通过标准：`拼接结果 == fixture 原文`（字符级）。

## 3. 目标逐条核对

### 目标 1 — 原消息整条可分页
- 左栏：`上一条` / `下一条` 切消息，`上翻` / `下翻` 翻页。
- F1/F2/F3 灌进 `cue_sources[0].body`，确认能一路翻到最后一页，
  且"第 X 页 / 共 Y 页"与拼接完整性（第 2 节）都成立。

### 目标 2 — 三条独立阅读路径 + 位置/总数
- 对白/建议：点"A 顺着说"→ 阅读区显示路线标题 + "第 X 页 / 共 Y 页"；
- 现场摘要：点"摘要"→ 标题显示"现场摘要" + 独立页码（不跟随对白页码）；
- A/B：点"显示 A"/"显示 B"→ 标题显示"版本 A"/"版本 B" + 独立页码；
- 三条路径来回切换，页码各自回到第 1 页，互不影响。
- F4/F5 同时用于对白路径与 A/B 路径，各自跑完逐页核对。

### 目标 3 — 不依赖源换行当"视觉行"
- F1（一条长中文）、F2（连续 ASCII）、F3（连续空格）都**没有**足够的源换行，
  若分页仍能推进且每页行数 ≤ 预算，即通过。
- F8（大量极短行 + 300 个"字"）检查源换行密集时不会一页一行地退化成几十页。

### 目标 4 — A/B 在没有 routes 时也能翻页
- 启动后直接点"A/B 对照"/"显示 A"/"显示 B"（此时 `cue_routes` 为空），
  然后点"上一页"/"下一页"，应能正常翻页并显示"第 X 页 / 共 Y 页"。
- 修前此路径会被 `if cue_routes.len() == 0 { … return }` 挡死；修后不应再被挡。

### 目标 5 — 状态行与操作按钮不得遮挡正文
- 两个视口分别截图：阅读区（右栏白底圆角框）里的文字应完整可见，
  底部状态行（"…仍是未发送的排练。"）与按钮行不得压住正文。
- 重点看 990 × 613（高度只有 613，按钮行最多）：F5 的最后一页
  （可能含源文本 `\n` 造成的多余空行）仍应在白框内。
- 412 × 892：确认按钮行不横向溢出（"对白/摘要/播放"、"A/B 对照/显示 A/显示 B"、
  左栏"上翻/下翻"三行）。

### 目标 6 — 不得用字节切片截断 UTF-8
- 由 `probe-plan.md` Probe 2/4 覆盖（算法层面已无任何字节切片）；
- 人工侧看 F6：emoji 与组合字符不得出现 `�`、方块、或截半的乱码。

### 目标 7 — 每页拼接后逐字符等于原始输入
- 见第 2 节"拼接完整性"；F1–F8 全部做一遍。

### 目标 8 — 播放/暂停/逐句/重播/切换路线使用正确页数，旧 timer 隔离
- 播放：点"播放"，确认逐页前进，到"共 Y 页"后自动停在末页并把按钮文字恢复"播放"；
- 暂停：播放中点"暂停"，停在当前页，按钮回"播放"；
- 手动翻页：播放中/暂停后点"上一页/下一页"，页码连续且不跳页；
- 重播：点"重播"回到第 1 页，总页数与播放前一致；
- 切换路线：播放中或暂停中点"A 顺着说/B 换问法/C 换玩法"，
  页码回到第 1 页，且**旧 route 的定时器不得继续翻页**（
  `cue_play_epoch` 递增隔离；观察 3 秒内不应出现"幽灵翻页"）；
- 摘要/A-B 路径下点"播放"：应自动切回对白路径并从头播放，或给出明确提示。

### 目标 9 — 事实/假设分离，排练不发送
- 确认界面文案仍在："原消息是事实线索；对白、摘要与 A/B 为逐页阅读的私下排练，
  仍需你判断。尚未发送。"
- 翻页/播放/切换路线过程中的状态行都带"仍是未发送的排练"或同类提示。
- 确认所有翻页路径都没有触发任何发送类 `host.request(...)`（只有
  `matrix.*` 读取、`octos.session.open` / `octos.turn.start` / `octos.turn.interrupt`
  这些排练相关调用）。
