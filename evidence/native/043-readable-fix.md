## 1. 改动摘要（对应任务 A1–A4）

固定行数分页 + 单面板切换 + 位置/总数 + 文本不重叠；字体不动、无响应式尺寸查询、不改宿主。

- **A1（原消息区 → 逐条翻读 + 位置）**：原消息从"只显示第 1 条"改为 `上一条 / 下一条` 逐条翻读，显示当前位置 `N / 12`(`1 / 12` … `12 / 12`)；整条消息一次渲染在卡片内、整条可读。
- **A2（七块产出 → 按固定行数分页，每页不裁）**：对白/假设路线输出改为按**固定行数分页**（`cue_page_lines = 2`），`上一页 / 下一页 / 重播` 翻页；标题行显示 `第 N 页 / 共 M 页`；每页文本在阅读卡片内完整显示，不出现半行/触底裁切。以"顺着这句"路线（5 行）为例 = `第 1 页 / 共 3 页` … `第 3 页 / 共 3 页`，翻到底可达末行（建议草稿）。
- **A3（草稿 + A/B → 全文入口）**：草稿与 A/B 共用**一个阅读面板**切换（`对白` / `A/B 对照` / `显示 A` / `显示 B`），避免左右分栏把文本挤窄；A、B 两版均走同一分页阅读，`版本 A/B` + `第 N 页 / 共 M 页`，整段可读。
- **A4（去重/压缩空白/给阅读面板高度）**：路线标题与页码计数移出卡片、并到一行紧凑表头（`header`，`flow:Right`，不再与正文堆叠重复）；右侧阅读卡片 `height:Fill` 吃满剩余高度；**字体不变**、**无 `KeyboardModifiers`/`let visible_size = [w,h]` 之类响应式尺寸查询**、**未改 card-host 宿主**。
